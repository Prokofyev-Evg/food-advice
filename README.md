# 🍳 Холодильник — что приготовить из того, что есть?

Первый вариант (MVP) сервиса рецептов: вводите продукты, получаете 3 подходящих рецепта на ужин.
Работает полностью локально: ключи API, регистрация и интернет не нужны.

## Что уже есть

- Ввод продуктов плашками (Enter или через запятую, × чтобы убрать, Backspace удаляет последнюю)
- Фильтры: «до 30 минут», «вегетарианское», «без глютена»
- Около 40 рецептов домашней кухни (`lib/recipes-data.ts`)
- Подбор: сначала рецепты, где не хватает меньше всего продуктов (`lib/recipes.ts`)
- Продукты узнаются по началу слова: «яйцо», «яиц», «куриное филе», «картошка» (`lib/catalog.ts`)
- Карточки: эмодзи, название, время, чего не хватает; по клику — ингредиенты (✅ есть / 🛒 купить) и шаги

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Как добавить рецепт

Допишите объект в массив `RECIPES` в `lib/recipes-data.ts`. Если нужного продукта нет в
`lib/catalog.ts`, сначала добавьте его туда (название и начала слов, по которым его узнавать).
