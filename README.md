# 🍳 Холодильник — что приготовить из того, что есть?

Первый вариант (MVP) сервиса рецептов: вводите продукты, получаете 3 рецепта на ужин.
Рецепты генерирует Claude через API Anthropic — своей базы рецептов нет.

## Что уже есть

- Ввод продуктов плашками (Enter или через запятую, × чтобы убрать, Backspace удаляет последнюю)
- Фильтры: «до 30 минут», «вегетарианское», «без глютена»
- Карточки рецептов: эмодзи, название, время, чего не хватает; по клику — ингредиенты и шаги
- API-роут `POST /api/recipes` со структурированным ответом (Zod-схема в `lib/recipes.ts`)

## Запуск

```bash
npm install
cp .env.example .env.local   # впишите ANTHROPIC_API_KEY
npm run dev
```

Откройте http://localhost:3000.

## Стек

Next.js (App Router) + Tailwind CSS, API-роуты Next.js, `@anthropic-ai/sdk`. Деплой — Vercel
(добавьте `ANTHROPIC_API_KEY` в переменные окружения проекта).
